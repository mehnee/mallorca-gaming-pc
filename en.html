Nothing missing: checklist for setup A

  • Reserve online at MediaMarkt with Recogida en tienda → Palma de Mallorca Fan: Acer Nitro 50, the chosen monitor, Corsair HS35 v2.
  • Windows: buy the Windows 11 Home code at MediaMarkt (145 €, arrives by email) — or skip it if his existing licence can move to the new PC (one bought separately can; one that came with an old PC cannot).
  • USB stick, 8GB or larger, prepared with Microsoft's free Media Creation Tool on another computer (German language is fine).
  • In the store: open the Acer box and check the keyboard and mouse; check the monitor box for a DisplayPort cable — buy one there if not.
  • At home: two free power sockets and a desk about 65 cm wide for the 27″ (about 75 cm for a 32″).
  • First start: monitor into the graphics card's DisplayPort (the lower, horizontal strip), set the full refresh rate in Windows display settings, create a Microsoft child account for screen time.
